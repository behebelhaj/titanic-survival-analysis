# Titanic Survival Analysis 🚢

## About
Exploratory Data Analysis (EDA) on the Titanic passenger dataset
to answer one question: What kind of passengers were more likely 
to survive?

## Key Findings
- Gender was the biggest factor:
  - Female: 74% survival rate
  - Male: 19% survival rate
- Passenger class was critical:
  - 1st class: 63% survival rate
  - 2nd class: 47% survival rate
  - 3rd class: 24% survival rate
- Combined insight:
  - 1st class female: 97% survival (almost guaranteed)
  - 3rd class male: 14% survival (almost certain death)
- Age had a small effect — survivors were slightly younger
